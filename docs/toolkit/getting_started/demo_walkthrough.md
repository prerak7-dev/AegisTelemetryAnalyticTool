# Portfolio Demo Walkthrough

This walkthrough is designed for a professional portfolio review.

## Recommended five-minute flow

### 1. Start with the product framing

Open:

```text
Operations > Command Center
```

Explain that the system turns gameplay telemetry into operational evidence.

Key message:

> This is a complete telemetry decision loop, not only a dashboard.

### 2. Launch a scenario

Open:

```text
Demo > Demo Control Center
```

Run:

```text
Weekend Event Meltdown
```

Point out:

- scenario library is configurable
- commands can be launched from the dashboard or copied manually
- raw ingestion appears before aggregate windows
- the feedback panel explains pipeline warmup

### 3. Show live pressure

Open:

```text
Operations > Command Center
```

Show:

- simulation pressure
- network pressure
- replication pressure
- physics pressure
- memory pressure
- player-impact pressure

### 4. Show incident explanation

Open:

```text
Incidents > Incident Dossier
Incidents > Incident Timeline
```

Explain:

- issue is detected by rules
- evidence is attached
- root-cause stages are configurable
- recommendation changes over time are visible

### 5. Show workflow maturity

Open:

```text
Incidents > Incident Workflow
```

Show:

- owner assignment
- status
- notes
- SLA state
- report export

### 6. Show analytical maturity

Open:

```text
Incidents > Baseline Intelligence
Incidents > Build Regression
Rules & Replay > Fix Validation
Data & Schemas > Analyst Toolkit
```

Explain:

- static thresholds are not enough
- build regressions matter for release readiness
- fixes should be validated against guardrails
- analysts can export evidence and continue in notebooks

## Strong closing line

> The project demonstrates gameplay telemetry, backend processing, operational analytics, configurable rules, evidence-backed recommendations, and analyst workflows in one coherent toolkit.
