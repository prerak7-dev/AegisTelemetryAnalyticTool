# Workspace Map

## Operations

| Workspace | Purpose |
|---|---|
| Command Center | Fleet-level pressure overview and multidimensional live health |
| Selected Server | Drill into a specific server and its recent performance signals |
| Scaling Readiness | Evaluate load, pressure, and readiness for traffic changes |

## Incidents

| Workspace | Purpose |
|---|---|
| Incident Dossier | Evidence-backed incident list and recommendations |
| Incident Workflow | Owner assignment, notes, status, SLA state, and report export |
| Incident Timeline | Historical replay of how an incident developed |
| Baseline Intelligence | Context-aware anomaly detection against historical behavior |
| Build Regression | Build-to-build performance comparison and release-readiness review |

## Rules & Replay

| Workspace | Purpose |
|---|---|
| Rule Testing | Test configured incident and recommendation rules |
| Fix Validation | Validate control/treatment improvements and guardrails |
| Recommendation Rules | Review and modify rule definitions |
| Timeline Stages | Review and modify root-cause timeline stages |

## Data & Schemas

| Workspace | Purpose |
|---|---|
| Data Quality | Validation failures and schema quality |
| Source Schemas | Source-profile adaptability |
| Query Performance | Dashboard query diagnostics and budgets |
| Performance Config | Active configuration values |
| Analyst Toolkit | Export evidence, SQL templates, and notebooks |
| Documentation | Professional toolkit documentation |

## Demo

| Workspace | Purpose |
|---|---|
| Demo Control Center | Launch scenarios, reset demo data, download runbooks |
