# Phase 11.3 — Demo Action Controls Styling

This patch improves control clarity in the Demo Control Center.

## Fixed

The action buttons now match the sharp workspace-tab language:

```text
Start scenario
Stop all generators
Reset demo data
Sidebar Refresh now
```

They now use:

```text
square edges
light paper surface
dark readable text
uppercase tab-like typography
blue hover/active underline
consistent width behavior
```

## Reset confirmation clarity

Previously, the reset checkbox appeared visually disconnected from `Reset demo data`.

The reset controls are now grouped together:

```text
Confirm reset of demo telemetry tables
Reset demo data
Requires confirmation. Clears only the configured demo tables.
```

This makes the checkbox purpose clear and keeps it aligned with the button it controls.
